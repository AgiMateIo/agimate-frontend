Расширение для Chromium-браузеров, которое превращает **живой браузер** — со всеми
логинами, сессиями, куками и открытыми вкладками — в источник инструментов для агентов.
Его домен — веб-страницы: навигация, чтение, действия. Desktop в том же семействе отвечает
за операционную систему, Android — за телефон.

## Два потребителя, один набор инструментов

- **Агенты AgiMate** — расширение подключается к платформе как обычное приложение, тем же
  способом, что desktop и Android.
- **Локальные MCP-клиенты** — Claude Code, Cursor, Claude Desktop и другие, через
  локальный мост, который выступает stdio MCP-сервером.

## Почему без локального процесса

Для работы с AgiMate локальный процесс не нужен вообще: service worker расширения сам
умеет и HTTP, и websocket, а значит расширение целиком является приложением-коннектором.
Ставится из Web Store в один клик — без установки чего-либо в систему, без регистрации
native messaging host и без разбирательств с путями манифеста, разными у Chrome, Brave,
Edge, Arc и Vivaldi.

Локальный мост существует только ради stdio-режима и остаётся необязательным.
