Агент — это набор из модели, навыков и подключений. Пустой агент уже умеет разговаривать;
всё остальное добавляется по мере надобности.

## Создать

Откройте список агентов и нажмите «Создать». Обязательное поле одно — имя.

> [!NOTE]
> Ключ агента показывается один раз, сразу после создания. Если он потерялся, его можно
> перевыпустить, но старый перестанет работать.

## Выбрать модель

Модель назначается на роль (`CHAT`, `SUMMARY` и другие), а не на агента целиком. Роль без
явной привязки разрешается через приоритеты провайдера.

## Поговорить

У каждого агента есть вкладка чата. Первое сообщение создаёт сессию, её заголовок потом
можно переименовать.

## Что дальше

Дайте агенту инструменты — это делается через подключения.
