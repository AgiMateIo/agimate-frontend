An agent is a model, some skills and some connections. An empty agent can already hold a
conversation; everything else is added when you need it.

## Create

Open the agent list and press "Create". There is one required field — the name.

> [!NOTE]
> The agent key is shown once, right after creation. If you lose it you can issue a new
> one, but the old key stops working.

## Pick a model

A model is bound to a purpose (`CHAT`, `SUMMARY` and others), not to the agent as a whole.
A purpose with no explicit binding resolves through the provider's priority list.

## Talk to it

Every agent has a chat tab. The first message creates a session, which you can rename
later.

## Next
